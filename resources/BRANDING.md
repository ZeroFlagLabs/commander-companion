# Commander Companion artwork

The selected concept is **Connected terminal**: a white monitor, cyan terminal prompt and cyan chain link on a navy rounded tile. It is original artwork generated for this project; the Desktop Commander logo is not used.

`Remote_Desktop_Commander_Launcher.png` is the full-resolution image with transparent corners. The matching ICO packages transparent PNG frames at 16, 20, 24, 32, 48, 64, 128 and 256 pixels for Windows. The legacy asset names are retained for compatibility with the existing project.

The final PNG was produced using the built-in image generation tool, with the previously selected four-concept sheet as its reference. The final prompt was:

> Use case: background-extraction / logo-brand. Edit target: the attached four-icon comparison sheet. Produce ONLY the TOP LEFT icon, option 1 Connected terminal, as one finished standalone Windows application icon. Preserve this chosen design closely: deep navy rounded square tile, bold clean white desktop monitor outline with white stand, bright cyan >_ terminal prompt, cyan two-link chain badge overlapping the monitor lower-right, navy cut-out separation around the chain. Same proportions and palette. Large centered icon, square canvas, small even transparent margin around the navy tile. True transparent alpha outside the rounded square. Crisp clean edges, legible when reduced to 16/32/48px. Remove ALL labels, other three icons and sheet background. No text, no extra elements, no watermark. This is the final asset for Commander Companion.
